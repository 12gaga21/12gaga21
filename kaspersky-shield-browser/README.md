## 🏗️ Архитектура проекта

### Основные компоненты

```
kaspersky-shield-browser/
├── src/                    # Исходный код
│   ├── main.cpp           # Точка входа приложения
│   ├── MainWindow.cpp     # Главное окно браузера
│   ├── SecurityManager.cpp # Менеджер безопасности
│   ├── ParentalControlManager.cpp # Родительский контроль
│   ├── DatabaseManager.cpp # Управление базой данных
│   ├── ProfileManager.cpp # Управление профилями
│   ├── KsnClient.cpp      # Клиент KSN API
│   └── AddressBar.cpp     # Адресная строка
├── include/               # Заголовочные файлы
│   ├── MainWindow.h
│   ├── SecurityManager.h
│   ├── ParentalControlManager.h
│   ├── DatabaseManager.h
│   ├── ProfileManager.h
│   ├── KsnClient.h
│   ├── AddressBar.h
│   └── CommonTypes.h      # Общие типы данных
├── tests/                 # Тесты
├── scripts/               # Скрипты сборки
├── resources/             # Ресурсы приложения
└── docs/                  # Документация
```

### Модульная архитектура

1. **UI Layer** (`MainWindow`, `AddressBar`)
   - Пользовательский интерфейс
   - Навигация и управление вкладками
   - Интеграция с менеджерами

2. **Security Module** (`SecurityManager`, `KsnClient`)
   - Проверка безопасности URL
   - Интеграция с KSN API
   - Блокировка опасных сайтов

3. **Parental Control Module** (`ParentalControlManager`, `ProfileManager`)
   - Управление профилями пользователей
   - Ограничения по времени и контенту
   - Логирование активности

4. **Database Layer** (`DatabaseManager`)
   - Хранение настроек и истории
   - Управление профилями
   - Логирование событий безопасности

## 🚀 Быстрый старт

### Требования

- **Qt 6.8.3+** (Core, Widgets, Gui, Network, Sql)
- **CMake 3.20+**
- **OpenSSL 3.0+**
- **SQLite 3.35+**
- **C++20** компилятор

### Сборка

```bash
# Клонирование репозитория
git clone <repository-url>
cd kaspersky-shield-browser

# Сборка проекта
./scripts/build.sh debug

# Запуск
./build_debug/KasperskyShieldBrowser
```

### Сборка в release режиме

```bash
./scripts/build.sh release
```

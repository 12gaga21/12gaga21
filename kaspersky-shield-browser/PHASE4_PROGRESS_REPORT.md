- **Логирование** всех операций в файл

#### 🔧 **Основные возможности:**
- ✅ **8 уровней безопасности** WebEngine
- ✅ **Проверка URL** на вредоносный контент
- ✅ **Категоризация сайтов** (Adult, Gambling, Violence, etc.)
- ✅ **Родительский контроль** с профилями
- ✅ **Кэширование результатов** (1000 записей, 24 часа TTL)
- ✅ **Статистика операций** (запросы, кэш, ошибки)
- ✅ **Валидация API ключей** Kaspersky

#### 📊 **Технические детали:**
```cpp
// Основные структуры
enum class UrlCheckResult { Safe, Malicious, Phishing, Suspicious, Blocked, Unknown, Error, Timeout };
enum class SiteCategory { General, News, Social, Shopping, Education, Entertainment, Adult, Gambling, Violence, Drugs, Weapons, Terrorism, Unknown };

// Конфигурация
struct Config {
    QString apiKey;                 // API ключ Kaspersky
    QString apiUrl;                 // URL API сервера
    int timeoutMs;                  // Таймаут запросов (10 сек)
    int maxRetries;                 // Максимальные повторы (3)
    int cacheSize;                  // Размер кэша (1000)
    int cacheExpiryHours;           // TTL кэша (24 часа)
    bool enableParentalControl;     // Родительский контроль
    bool enableRealTimeCheck;       // Проверка в реальном времени
    bool enableCaching;             // Кэширование
    bool enableLogging;             // Логирование
};
```

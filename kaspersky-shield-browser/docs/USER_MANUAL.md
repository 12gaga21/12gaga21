## 📘 Введение

**Kaspersky Home Shield Browser** - это защищенный веб-браузер с встроенными функциями безопасности, родительского контроля и управления профилями. Разработан для обеспечения максимальной защиты всей семьи при работе в интернете.

### Основные возможности:

- ✅ **8 уровней безопасности** - от минимальной до максимальной защиты
- 🛡️ **Kaspersky Security Network** - проверка URL в реальном времени
- 👨‍👩‍👧 **Управление профилями** - отдельные настройки для каждого члена семьи
- 🔒 **Родительский контроль** - фильтрация контента и временные ограничения
- 📊 **Статистика безопасности** - отслеживание угроз и блокировок
- 🌐 **Современный веб-движок** - Qt WebEngine (на базе Chromium)

## 💿 Установка

### Системные требования:

**Минимальные:**
- Процессор: Intel Core i3 / AMD Ryzen 3
- Оперативная память: 4 GB
- Свободное место: 500 MB
- ОС: Windows 10/11, macOS 10.15+, Linux Ubuntu 20.04+

**Рекомендуемые:**
- Процессор: Intel Core i5 / AMD Ryzen 5
- Оперативная память: 8 GB
- Свободное место: 1 GB
- ОС: Windows 11, macOS 13+, Linux Ubuntu 22.04+

### Сборка из исходного кода:

```bash
# 1. Установка зависимостей (Ubuntu/Debian)
sudo apt install build-essential cmake qt6-base-dev qt6-webengine-dev \
                 libssl-dev libsqlite3-dev

# 2. Клонирование репозитория
git clone https://github.com/12gaga21/12gaga21
cd 12gaga21/kaspersky-shield-browser

# 3. Сборка проекта
./scripts/rebuild_all.sh

# 4. Запуск
./build_debug/KasperskyShieldBrowser
```

## 🚀 Первый запуск

### Шаг 1: Запуск браузера

При первом запуске браузер:
- Создаст базу данных SQLite
- Инициализирует профиль "Родитель" по умолчанию
- Откроет домашнюю страницу Kaspersky

### Шаг 2: Проверка безопасности

В статус-баре вы увидите:
- ✅ **Зеленая галочка** - безопасный сайт
- ⚠️ **Желтый восклицательный знак** - подозрительный сайт
- 🛑 **Красный знак стоп** - опасный сайт (заблокирован)
- ❓ **Серый вопросительный знак** - неизвестный статус

### Шаг 3: Базовая навигация

**Адресная строка:**
- Введите URL: `example.com` → автоматически станет `https://example.com`
- Поисковый запрос: `погода сегодня` → поиск в Google
- Нажмите `Enter` для перехода

**Кнопки навигации:**
- `←` Назад
- `→` Вперед
- `↻` Обновить
- `⏹` Остановить загрузку

## 🌐 Основные функции

### 1. Работа с вкладками

**Создание новой вкладки:**
- Кнопка `+ Новая вкладка` в тулбаре
- Горячая клавиша: `Ctrl+T` (Win/Linux), `Cmd+T` (Mac)
- Меню: File → New Tab

**Закрытие вкладки:**
- Крестик на вкладке
- Горячая клавиша: `Ctrl+W` (Win/Linux), `Cmd+W` (Mac)
- Меню: File → Close Tab

**Переключение между вкладками:**
- Клик мышью по вкладке
- `Ctrl+Tab` / `Ctrl+Shift+Tab` для перехода вперед/назад
- `Ctrl+1-9` для перехода к вкладке по номеру

### 2. Навигация

**Переход по URL:**
1. Кликните в адресную строку
2. Введите URL или поисковый запрос
3. Нажмите `Enter`

**Различие между URL и поиском:**
- URL: `google.com`, `https://example.com/page`
- Поиск: `как приготовить пиццу`, `weather today`

**История:**
- `Alt+←` Назад
- `Alt+→` Вперед
- `F5` или `Ctrl+R` Обновить

### 3. Индикаторы безопасности

**Статус-бар (внизу):**
```
✅ Безопасно: google.com          - Сайт проверен и безопасен
⚠️ Подозрительно: unknown.com     - Будьте осторожны
🛑 Опасно: malware-site.com       - Доступ заблокирован
❓ Неизвестно: new-site.com       - Проверка не завершена
```

**При блокировке:**
Появится диалог с предупреждением:
```
┌─────────────────────────────────┐
│  URL Заблокирован              │
│                                 │
│  http://malicious-site.com     │
│  Причина: Malicious content    │
│                                 │
│         [ OK ]                  │
└─────────────────────────────────┘
```

## 🔒 Настройки безопасности

### Открытие настроек:

**Способ 1:** Кнопка `🔒` в тулбаре  
**Способ 2:** Меню: Security → Security Status

### Уровни безопасности (1-8)

#### 🟢 Уровень 1-2: Минимальная защита
- JavaScript полностью включен
- Плагины разрешены
- Минимальные ограничения
- **Рекомендуется для:** Опытных пользователей, доверенных сайтов

#### 🟡 Уровень 3-4: Средняя защита
- JavaScript с ограничениями
- Некоторые плагины заблокированы
- WebGL отключен
- **Рекомендуется для:** Повседневного использования

#### 🟠 **Уровень 5-6: Высокая защита (Рекомендуемый)**
- Строгий контроль JavaScript
- Все плагины заблокированы
- XSS аудит включен
- WebRTC ограничен
- **Рекомендуется для:** Большинства пользователей

#### 🔴 Уровень 7-8: Максимальная защита
- Почти все опасные функции отключены
- Параноидальный режим
- Может нарушить работу некоторых сайтов
- **Рекомендуется для:** Детских профилей, максимальной безопасности

### Настройки защиты

```
☑️ Использовать Kaspersky Security Network (KSN)
☑️ Включить кэширование результатов проверки
☑️ Блокировать вредоносные сайты
☑️ Блокировать фишинговые сайты
☑️ Предупреждать о подозрительных сайтах
```

### Настройки производительности

**Время жизни кэша:** 1-168 часов (по умолчанию: 24)  
**Таймаут запроса:** 1-30 секунд (по умолчанию: 5)

**Очистка кэша:**
Нажмите кнопку "Очистить кэш" для удаления всех сохраненных результатов проверки.

### Статистика безопасности

В реальном времени отображается:
- Всего проверок: количество проверенных URL
- Заблокировано URL: количество заблокированных угроз
- Безопасных URL: количество безопасных сайтов
- Подозрительных URL: количество подозрительных сайтов
- Попаданий в кэш: количество использований кэша
- Коэффициент попаданий: эффективность кэша в %

## 👥 Управление профилями

### Открытие менеджера профилей:

**Кнопка:** `👤` в тулбаре  
**Меню:** Profiles → Manage Profiles

### Типы профилей

#### 👨‍👩‍👧 Родитель
- Без ограничений на контент
- Полный доступ ко всем настройкам
- Может управлять другими профилями

#### 👦 Ребенок (Child)
- Максимальные ограничения
- Блокировка: взрослого контента, насилия, азартных игр, наркотиков, оружия, терроризма
- Обязательный дневной лимит времени

#### 👨‍🎓 Подросток (Teen)
- Умеренные ограничения
- Блокировка: взрослого контента, азартных игр, наркотиков, оружия, терроризма
- Опциональный лимит времени

### Создание нового профиля

1. Откройте менеджер профилей
2. Нажмите `➕ Новый`
3. Введите имя профиля
4. Выберите тип профиля
5. Установите дневной лимит (опционально)
6. Нажмите `💾 Сохранить`

### Редактирование профиля

1. Выберите профиль из списка
2. Нажмите `✏️ Изменить`
3. Измените параметры
4. Нажмите `💾 Сохранить`

### Переключение профиля

**Способ 1:** В менеджере профилей:
1. Выберите профиль
2. Нажмите `🔄 Переключить`

**Способ 2:** Горячая клавиша:
- `Ctrl+Shift+P` - следующий профиль

### Удаление профиля

1. Выберите профиль из списка
2. Нажмите `🗑️ Удалить`
3. Подтвердите удаление

⚠️ **Примечание:** Профиль "Родитель" удалить нельзя.

## 👨‍👩‍👧 Родительский контроль

### Открытие настроек:

**Кнопка:** `🔐` в тулбаре  
**Меню:** Security → Parental Control

### Фильтрация контента

Выберите категории для блокировки:

```
🔞 Контент для взрослых
🎰 Азартные игры
💥 Насилие
💊 Наркотики
🔫 Оружие
⚠️ Терроризм
📱 Социальные сети
🛒 Интернет-магазины
```

**Рекомендации:**
- **Ребенок:** Все кроме социальных сетей и магазинов
- **Подросток:** Взрослый контент, азартные игры, наркотики, оружие, терроризм
- **Родитель:** Без ограничений

### Временные ограничения

**Дневной лимит:**
- Установите количество минут (0 = без ограничений)
- При достижении лимита появится предупреждение
- Сброс лимита происходит в 00:00

**Режим сна:**
```
☑️ Включить режим сна
Время сна: 22:00 - 07:00
```

В указанное время доступ к браузеру будет ограничен.

### Статистика

Отслеживайте активность профиля:
- Заблокировано сегодня: количество заблокированных попыток
- Использовано времени: минут использования сегодня
- Осталось времени: оставшийся дневной лимит

### История активности

Таблица последних 5 посещений:
```
Время    | URL                  | Категория | Статус
---------|----------------------|-----------|-------------
10:15:32 | youtube.com          | Video     | ✅ Разрешено
10:16:45 | gambling-site.com    | Gambling  | 🛑 Заблокировано
```

**Действия:**
- `📖 Показать всю историю` - полная история (в разработке)
- `🗑️ Очистить историю` - удалить всю историю активности

## ❓ Часто задаваемые вопросы

### 1. Как работает проверка безопасности URL?

Когда вы переходите на сайт:
1. URL отправляется в **SecurityManager**
2. Проверяется локальный кэш
3. Если нет в кэше, запрос отправляется в **KSN API**
4. Результат анализируется и отображается в статус-баре
5. Если сайт опасен, доступ блокируется

### 2. Что делать, если безопасный сайт заблокирован?

1. Проверьте уровень безопасности (возможно, слишком высокий)
2. Проверьте настройки родительского контроля
3. Добавьте сайт в белый список (в разработке)
4. Переключитесь на профиль "Родитель"

### 3. Как сбросить пароль профиля?

В текущей версии пароли не используются. Для защиты используйте:
- Пароль на уровне ОС
- Блокировку экрана при отсутствии

### 4. Можно ли использовать браузер без интернета?

Да, но:
- Проверка KSN будет недоступна
- Будет использоваться локальная классификация
- Некоторые функции могут работать ограниченно

### 5. Где хранятся данные браузера?

**База данных:**
- Windows: `C:/Users/<user>/AppData/Local/KasperskyShieldBrowser/kaspersky_shield.db`
- Linux: `~/.local/share/KasperskyShieldBrowser/kaspersky_shield.db`
- macOS: `~/Library/Application Support/KasperskyShieldBrowser/kaspersky_shield.db`

**Кэш:**
- В памяти приложения (не сохраняется после закрытия)

### 6. Как экспортировать настройки?

В текущей версии экспорт настроек не реализован. Планируется в следующей версии.

### 7. Поддерживается ли синхронизация между устройствами?

Пока нет. Синхронизация запланирована в Фазе 8 (Q4 2025).

## 🔧 Устранение неполадок

### Браузер не запускается

**Проблема:** Ошибка при запуске  
**Решение:**
1. Проверьте зависимости: `ldd ./KasperskyShieldBrowser`
2. Убедитесь, что Qt 6.5+ установлен
3. Проверьте логи в консоли

### Сайты не загружаются

**Проблема:** Белый экран или ошибка загрузки  
**Решение:**
1. Проверьте интернет-соединение
2. Отключите родительский контроль временно
3. Понизьте уровень безопасности до 5
4. Очистите кэш

### Высокое использование памяти

**Проблема:** Браузер занимает много RAM  
**Решение:**
1. Закройте неиспользуемые вкладки
2. Очистите кэш в настройках безопасности
3. Перезапустите браузер
4. Уменьшите время жизни кэша

### Проверка KSN не работает

**Проблема:** Все URL показываются как "Unknown"  
**Решение:**
1. Проверьте интернет-соединение
2. Убедитесь, что KSN включен в настройках
3. Проверьте настройки файрвола
4. Увеличьте таймаут запроса до 10 секунд

### База данных повреждена

**Проблема:** Ошибки при работе с профилями  
**Решение:**
1. Закройте браузер
2. Удалите файл БД: `kaspersky_shield.db`
3. Запустите браузер снова (БД создастся автоматически)
4. Настройте профили заново

### Логи для отладки

Запустите браузер с выводом логов:
```bash
./KasperskyShieldBrowser 2>&1 | tee browser.log
```

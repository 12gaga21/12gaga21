## ✨ Что такое Kaspersky Shield Browser?

**Kaspersky Shield Browser** — это современный безопасный браузер для всей семьи с встроенной защитой Kaspersky Security Network.

### Главные преимущества

```
✅ Простой и понятный интерфейс (как Chrome/Edge)
✅ Встроенная защита от угроз (блокировка вирусов, фишинга)
✅ Родительский контроль (защита детей онлайн)
✅ Приватность (блокировка трекеров, fingerprint защита)
✅ Быстрая работа (современный движок Chromium)
✅ Синхронизация (между устройствами)
```

## 📥 Установка

### Windows

```bash
1. Скачайте установщик: KasperskyShieldBrowser-2.5.0-Setup.exe
2. Запустите установщик (двойной клик)
3. Следуйте инструкциям мастера установки
4. Готово! Браузер автоматически запустится
```

### macOS

```bash
1. Скачайте: KasperskyShieldBrowser-2.5.0.dmg
2. Откройте DMG файл
3. Перетащите иконку в папку Applications
4. Запустите из Applications
```

### Linux

```bash
# Debian/Ubuntu
sudo dpkg -i kaspersky-shield-browser_2.5.0_amd64.deb

# Fedora/RHEL
sudo rpm -i kaspersky-shield-browser-2.5.0.x86_64.rpm

# Arch Linux
sudo pacman -U kaspersky-shield-browser-2.5.0-x86_64.pkg.tar.zst
```

## 🌐 Основные функции

### 1. Навигация (как в Chrome)

```
┌──────────────────────────────────────────────────────┐
│ [←] [→] [↻]  [🔍 Поиск или введите адрес]  [⭐] [⚙️] │
└──────────────────────────────────────────────────────┘
```

**Кнопки:**
- `←` `→` — Назад/Вперёд
- `↻` — Обновить страницу
- `🔍` — Адресная строка (омнибокс)
- `⭐` — Закладки
- `⚙️` — Настройки

### 2. Адресная строка (Омнибокс)

```
Что можно вводить:
  • URL:       google.com
  • Поиск:     погода в москве
  • Команды:   :history, :bookmarks
```

**Примеры:**
```
google.com              → Откроет Google
погода в москве         → Поиск в Google
youtube.com             → Откроет YouTube
:history                → Откроет историю
```

### 3. Вкладки

```
[🏠 Главная] [📰 Новости] [+]
```

**Управление вкладками:**
- `Ctrl + T` — Новая вкладка
- `Ctrl + W` — Закрыть вкладку
- `Ctrl + Tab` — Переключение между вкладками
- `Ctrl + Shift + T` — Восстановить закрытую вкладку

### 4. Закладки

```
Добавить в закладки:
  • Ctrl + D
  • Клик по звёздочке ⭐

Управление:
  • Ctrl + Shift + B — Показать панель закладок
  • Ctrl + Shift + O — Менеджер закладок
```

### 5. История

```
Открыть историю:
  • Ctrl + H
  • Меню → История

Очистка:
  • Ctrl + Shift + Delete
```

## 📚 Частые вопросы (FAQ)

### 1. Как импортировать закладки из Chrome?

```
1. Настройки → Импорт данных
2. Выбрать "Google Chrome"
3. Отметить "Закладки"
4. [Импортировать]
```

### 2. Как изменить поисковую систему?

```
1. Настройки → Поиск
2. Выбрать поисковую систему:
   ○ Google (по умолчанию)
   ○ Bing
   ○ Яндекс
   ○ DuckDuckGo (приватный)
```

### 3. Как заблокировать сайт?

```
1. Настройки → Безопасность
2. Чёрный список сайтов
3. [Добавить сайт]
4. Ввести URL (например: example.com)
5. [Сохранить]
```

### 4. Как отключить рекламу?

```
Встроенный блокировщик рекламы:
1. Настройки → Конфиденциальность
2. Блокировка содержимого
3. ☑ Блокировать рекламу
4. ☑ Блокировать всплывающие окна
```

### 5. Как обновить браузер?

```
Автоматические обновления:
  ✅ Включены по умолчанию

Проверить вручную:
  Меню → Справка → О программе
  → [Проверить обновления]
```

### 6. Как сбросить настройки?

```
1. Настройки → Дополнительно
2. Сброс настроек
3. [Восстановить настройки по умолчанию]
4. Подтвердить сброс
```

## 💡 Советы для начинающих

### 1. Используйте омнибокс для всего

```

```

```
  │   ├── Gmail
  │   └── Slack
  ├── Личное/
  │   ├── YouTube
  │   └── VK

```

## О продукте

### Что такое Kaspersky Shield Browser?

**Kaspersky Shield Browser** — это профессиональный безопасный веб-браузер для семей и организаций, разработанный с использованием технологий Kaspersky Lab.

### Ключевые особенности

```
🛡️ БЕЗОПАСНОСТЬ
   • Защита от вирусов и вредоносного ПО в реальном времени
   • Блокировка фишинговых сайтов
   • Проверка загружаемых файлов
   • Защита от трекеров и fingerprinting

👨‍👩‍👧‍👦 СЕМЕЙНАЯ ЗАЩИТА
   • Родительский контроль с гибкими настройками
   • Фильтрация контента по категориям
   • Временные ограничения использования
   • Подробные отчёты об активности детей

🚀 ПРОИЗВОДИТЕЛЬНОСТЬ
   • Быстрый движок на базе Chromium
   • Оптимизированное потребление памяти
   • Поддержка современных веб-стандартов
   • Плавная работа на любых устройствах

🔒 ПРИВАТНОСТЬ
   • Блокировка трекеров (2,000+ списков)
   • Защита от fingerprinting
   • Безопасный режим инкогнито
   • End-to-end шифрование синхронизации

💼 БИЗНЕС-ФУНКЦИИ
   • Централизованное управление (для организаций)
   • Политики безопасности
   • Аудит и логирование
   • Интеграция с корпоративными системами
```

## Установка и первый запуск

### Скачивание

**Официальный сайт:** https://kaspersky-shield.com/download

```
Выберите вашу платформу:

┌─────────────┬─────────────┬─────────────┐
│   Windows   │    macOS    │    Linux    │
│   [Download]│  [Download] │  [Download] │
└─────────────┴─────────────┴─────────────┘

Размер загрузки: ~150 МБ
Время установки: ~5 минут
```

### Процесс установки

#### Windows

```
1. Запустите KasperskyShieldBrowser-Setup.exe
2. Примите условия лицензионного соглашения
3. Выберите папку установки (по умолчанию: C:\Program Files\Kaspersky Shield Browser)
4. Выберите дополнительные опции:
   ☑ Создать ярлык на рабочем столе
   ☑ Добавить в меню Пуск
   ☑ Сделать браузером по умолчанию
5. Нажмите "Установить"
6. Дождитесь завершения установки
7. Нажмите "Запустить браузер"
```

#### macOS

```
1. Откройте KasperskyShieldBrowser.dmg
2. Перетащите иконку приложения в папку Applications
3. Откройте Applications и найдите Kaspersky Shield Browser
4. При первом запуске подтвердите открытие (System Preferences → Security)
5. Браузер готов к работе
```

#### Linux

```bash
# Debian/Ubuntu
wget https://kaspersky-shield.com/downloads/kaspersky-shield-browser_2.5.0_amd64.deb
sudo dpkg -i kaspersky-shield-browser_2.5.0_amd64.deb
sudo apt-get install -f  # Установка зависимостей

# Fedora
wget https://kaspersky-shield.com/downloads/kaspersky-shield-browser-2.5.0.x86_64.rpm
sudo dnf install kaspersky-shield-browser-2.5.0.x86_64.rpm

# Запуск
kaspersky-shield-browser
```

### 3. Омнибокс (адресная строка)

**Многофункциональная строка ввода:**

#### Поиск

```
Введите: "погода в москве"
→ Поиск в Google

Введите: "картинки кошек"
→ Поиск в Google Images
```

#### Навигация по URL

```
Введите: "google.com"
→ https://www.google.com

Введите: "youtube.com/watch?v=..."
→ Откроет видео на YouTube
```

#### Встроенные команды

```
:history      → Открыть историю
:bookmarks    → Открыть закладки
:downloads    → Открыть загрузки
:settings     → Открыть настройки
:help         → Открыть справку
```

#### Калькулятор

```
Введите: "2+2"
→ Результат: 4

Введите: "100*0.8"
→ Результат: 80
```

#### Конвертация единиц

```
Введите: "100 usd в rub"
→ 100 USD = 9,000 RUB

Введите: "10 km в miles"
→ 10 km = 6.21 miles
```

## Основные функции

### Работа с вкладками

#### Создание вкладок

```
Способы создания:
  • Ctrl + T
  • Клик по кнопке [+]
  • Средний клик по ссылке
  • Ctrl + клик по ссылке
```

#### Управление вкладками

```
Переключение:
  • Ctrl + Tab          - Следующая
  • Ctrl + Shift + Tab  - Предыдущая
  • Ctrl + 1...9        - Вкладка по номеру

Закрытие:
  • Ctrl + W           - Закрыть текущую
  • Ctrl + Shift + T   - Восстановить закрытую
  • Средний клик на вкладке

Группировка:
  • Правый клик → Добавить в группу
  • Выбрать цвет группы
  • Свернуть/развернуть группу
```

#### Закреплённые вкладки

```
Для часто используемых сайтов:

1. Правый клик на вкладке
2. "Закрепить вкладку"

Преимущества:
  ✅ Компактный размер (только иконка)
  ✅ Всегда слева
  ✅ Открываются при запуске
  ✅ Нельзя случайно закрыть
```

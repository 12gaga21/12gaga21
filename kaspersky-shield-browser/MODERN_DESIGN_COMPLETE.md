## 🔄 ПЕРЕКЛЮЧЕНИЕ ТЕМ

### ThemeManager

**Класс для управления:**
```cpp
class ThemeManager {
    enum class Theme { Light, Dark, System };
    void applyTheme(Theme theme);
    void toggleTheme();
    void loadSavedTheme();
    void saveTheme();
};
```

**Использование:**
```cpp
// Инициализация
m_themeManager = new ThemeManager(this);
m_themeManager->loadSavedTheme();

// Переключение
m_themeManager->toggleTheme();
```

**Кнопка в тулбаре:**
```
[🌓] - Переключить тему
```

**Сохранение:**
```
QSettings("Kaspersky", "ShieldBrowser")
Ключ: "theme"
Значения: "light" | "dark" | "system"
```

## 🚀 КАК ИСПОЛЬЗОВАТЬ

### 1. Запуск браузера

```bash
cd kaspersky-shield-browser
./scripts/rebuild_all.sh
./build_debug/KasperskyShieldBrowser
```

Автоматически загружается темная тема (или последняя использованная).

### 2. Переключение темы

**Кнопка 🌓 в тулбаре** - мгновенное переключение

### 3. Выбор темы при запуске

Тема сохраняется автоматически и загружается при следующем запуске.

## 🎓 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### CSS Особенности

**Переменные:**
```css
* {
    --bg-primary: #0F0F0F;
    --accent-primary: #00A88E;
    --text-primary: #FFFFFF;
}
```

**Transitions:**
```css
* {
    transition: all 0.2s cubic-bezier(0.4, 0.0, 0.2, 1);
}
```

**Focus Effects:**
```css
:focus {
    border-color: #00A88E;
    box-shadow: 0 0 0 4px rgba(0, 168, 142, 0.15);
}
```

### Qt Integration

**Применение темы:**
```cpp
QString styleSheet = loadStyleSheet("resources/styles/modern_dark.qss");
QApplication::instance()->setStyleSheet(styleSheet);
QApplication::setStyle(QStyleFactory::create("Fusion"));
```

**Fusion style** используется как база для лучшей совместимости.

# 🤝 Руководство по участию в разработке

Спасибо за интерес к проекту **Kaspersky Home Shield Browser**! Мы приветствуем любой вклад в развитие проекта.

## 🚀 Как начать

### 1. Форк репозитория
```bash
# Создайте форк репозитория на GitHub
# Затем клонируйте ваш форк
git clone https://github.com/YOUR_USERNAME/kaspersky-home-shield-browser.git
cd kaspersky-home-shield-browser
```

### 2. Настройка окружения
```bash
# Добавьте upstream репозиторий
git remote add upstream https://github.com/12gaga21/kaspersky-home-shield-browser.git

# Создайте ветку для ваших изменений
git checkout -b feature/your-feature-name
```

### 3. Установка зависимостей
```bash
# Убедитесь, что у вас установлены все зависимости
# См. docs/REQUIREMENTS.md для подробной информации

# Соберите проект
./scripts/build.sh

# Запустите тесты
./scripts/test_webengine.sh
./scripts/test_functionality.sh
```

## 🔄 Процесс Pull Request

### 1. Подготовка
```bash
# Убедитесь, что ваша ветка актуальна
git fetch upstream
git rebase upstream/main

# Запустите тесты
./scripts/test_webengine.sh
./scripts/test_functionality.sh
```

### 2. Создание PR
- Заполните шаблон Pull Request
- Опишите изменения подробно
- Укажите связанные issues
- Добавьте скриншоты, если применимо

### 3. Обзор кода
- Отвечайте на комментарии ревьюеров
- Вносите необходимые изменения
- Обновляйте PR по мере необходимости

## 🏷️ Система тегов

### Issues
- `bug` - Ошибка в коде
- `enhancement` - Предложение новой функции
- `documentation` - Проблемы с документацией
- `question` - Вопросы и обсуждения
- `help wanted` - Нужна помощь сообщества

### Pull Requests
- `ready for review` - Готов к обзору
- `work in progress` - В процессе разработки
- `needs testing` - Требует тестирования
- `breaking change` - Критические изменения

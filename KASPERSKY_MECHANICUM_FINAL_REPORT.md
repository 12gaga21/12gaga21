
### 2. Интеграция в Qt браузер

```cpp
// В MainWindow.cpp
void MainWindow::createNewTab(const QUrl &url) {
    QWebEngineView *view = new QWebEngineView(this);
    
    // Загрузить Kaspersky dashboard как home page
    if (url.isEmpty()) {
        view->load(QUrl("qrc:/homepage/kaspersky-main-interface.html"));
    } else {
        view->load(url);
    }
    
    m_tabWidget->addTab(view, "New Tab");
}
```

### 3. Применить Mechanicum тему

```cpp
// В ThemeManager
m_themeManager->applyTheme(ThemeManager::Theme::Mechanicum);
```
